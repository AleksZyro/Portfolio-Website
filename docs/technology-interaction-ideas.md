# Technologie-Interaktionen: Ideen zur gemeinsamen Auswahl

Noch keine neue Interaktion umgesetzt. Die bestehende Auswahl pro Kategorie
bleibt erhalten. Vorschläge passend zu Aleksandars Projekten, ohne spielerische
Level oder erfundene Kompetenzprozente:

1. **Technologie → echte Verwendung.** Bei Auswahl von Python erscheinen etwa
   FolioLint und das konkrete Problem, für das Python eingesetzt wurde.
   Auswahl von React verweist auf PathLab und SortLab. Direkter Sprung zum
   passenden Projekt, Text und Nachweis statt einer unbelegten Skill-Bewertung.
2. **Ein Stack aus mehreren Reihen.** Eine Auswahl pro Kategorie ergibt ein
   kleines Architekturdiagramm: Oberfläche, Backend, Datenbank und Deployment.
   Nur Kombinationen aus tatsächlich vorhandenen Projekten als «eingesetzt»
   markieren; andere Kombinationen gegebenenfalls klar als Lernidee bezeichnen.
3. **Ein gemeinsamer Ablauf.** Statt einzelner isolierter Infotexte zeigen die
   gewählten Technologien, was beim Klicken einer Aktion passiert: Browser →
   API → Datenbank → Antwort. Die Abschnitte sind mit Tastatur und Touch bedienbar.
4. **Mini-Beispiel auf Wunsch.** Ein kompakter Vorher-/Nachher-Vergleich oder
   kurzer Codeausschnitt pro Auswahl. Kein automatisch laufender Editor und
   keine zusätzliche Animation im Hintergrund. Erst bei expliziter Aktion laden.

Empfehlung: mit 1 beginnen. Es verknüpft die vorhandene Auswahl unmittelbar mit
belegbaren Arbeiten und ist leicht, verständlich und gut automatisiert prüfbar.
Danach gegebenenfalls 2 als gemeinsame Ansicht über die Kategorien ergänzen.

Prüfen: Auswahlzustand, Fokus und Touch, sinnvolle Kombinationen, vollständige
Übersetzungen und richtige Projektverknüpfungen. Entscheidung vor Umsetzung.
